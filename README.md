# Craft Corner

A handmade marketplace platform that connects local artisans with customers worldwide.

## About Project

Craft Corner is a full-stack e-commerce website designed to showcase and sell handmade products created by local artisans. Users can explore unique crafts, view product details, and place orders.

The platform also provides an admin dashboard to manage products, categories, customers, and orders.

## Features

### User Features
- Browse handmade products
- View product details
- Product categories
- Search products
- Place orders

### Admin Features
- Admin dashboard
- Add new products
- Edit and delete products
- Manage categories
- Manage orders
- Manage customers

## Tech Stack
